# Tana Organization visual assets

This folder is reserved for public, privacy-safe visuals used by the Tana Organization case study.

Acceptable assets:

- recreated system-overview diagrams;
- fabricated information-flow examples;
- fully sanitized screenshots with no personal content;
- before-and-after workflow comparisons made from fictional data.

Do not add:

- exports or screenshots from the private working Tana workspace;
- personal notes, correspondence, names, or sensitive data;
- workspace names, node identifiers, or internal links;
- tokens, credentials, environment files, or machine-specific details.

The first portfolio version uses text-based diagrams embedded directly in `projects/tana-organization.md`, so it remains portable and renders without additional dependencies.
